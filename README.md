# Expense Tracker System

A simple console-based **Expense Tracker System** built with Python. This project helps users manage daily expenses by adding, viewing, searching, updating, and deleting expense records. It also provides expense analysis such as total, highest, and lowest expenses.

## Features

- Add a new expense
- View all expenses
- Search expense by ID
- Update expense details
- Delete an expense
- Calculate total expenses
- Display highest expense
- Display lowest expense
- Prevent duplicate Expense IDs
- Validate user input using exception handling
